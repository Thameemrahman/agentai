Friday — AI Voice Assistant

Overview

Friday is a Python-based AI voice assistant project that explores real-time conversational AI and tool integration. It uses LiveKit Agents and Google Gemini Realtime to build an interactive assistant experience.

Technologies Used

- Python
- LiveKit Agents
- Google Gemini Realtime

Project Structure

- "agent.py" — Main agent setup and execution.
- "prompt.py" — Assistant instructions and personality.
- "tool.py" — Tool definitions and related functionality.
- "requirements.txt" — Project dependencies.

Key Learning Areas

- AI agent development using Python
- Real-time voice interaction
- Prompt engineering
- Integrating tools with an AI assistant

Setup

Install the project dependencies:

pip install -r requirements.txt

Configure the environment variables required by the project before running it.

Run the Project

Run the following command from the project directory:

python agent.py dev
